# The Open Logic Text — edición en español

Adaptación independiente en español del [Open Logic Project](https://openlogicproject.org/), bajo CC BY 4.0. Es una edición asistida por IA y no oficial; no implica el respaldo del proyecto original.

Esta edición figura en el [catálogo central de traducciones](https://github.com/KokunoYumeto/OpenLogic-translations). La cobertura de las fuentes traducidas y la cobertura de un lector PDF se verifican por separado.

## Leer y descargar

- [Lector publicado en GitHub — r4](https://github.com/KokunoYumeto/OpenLogic-es/releases/download/v2026-08-20-r4/00_OLP_es_CURRENT_LINKED_READER.pdf)
- [Fuentes editables, evidencia y manifiesto de r4](https://github.com/KokunoYumeto/OpenLogic-es/releases/tag/v2026-08-20-r4)
- [Archivo Zenodo de la edición](https://doi.org/10.5281/zenodo.21997720)

Los cuatro archivos de GitHub r4 se descargaron anónimamente el 4 de septiembre de 2026 y coinciden con los tamaños y el manifiesto SHA-256 publicados. El lector tiene 1.058 páginas. Zenodo ofrece actualmente una versión distinta, identificada como r2; no es una copia idéntica del lector GitHub r4.

## Alcance y trabajo pendiente

La auditoría local actual verifica 722 archivos traducidos contra su registro de hashes. Sin embargo, el registro de compilación del lector local posterior r6 carga 642 de esos archivos, no los 722. Integrar y verificar una edición independiente con el corpus completo sigue pendiente. Esta medición del lector local r6 no se presenta como una nueva auditoría de la compilación pública r4.

Los archivos históricos `RELEASE_QA.json`, `ARTIFACT_SHA256.tsv` y `.zenodo.json` describen el candidato r5. Se conservan como evidencia, pero no prueban la existencia de una publicación GitHub r5 ni la identidad de los archivos locales posteriores. Los enlaces de lectura y citación ya no apuntan a ese lanzamiento inexistente.

Véase [PUBLICATION_STATUS.json](PUBLICATION_STATUS.json) para las identidades verificadas y las diferencias entre versiones. Las revisiones exactas de las fuentes y la atribución se conservan en [TRANSLATION_NOTES.md](TRANSLATION_NOTES.md) y [LICENSE.md](LICENSE.md).
