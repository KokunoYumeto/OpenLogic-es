# The Open Logic Text — edición en español

El Open Logic Project es una colección de código abierto y acceso abierto de
materiales sobre lógica avanzada, dirigida principalmente a filósofos, aunque
también resulta adecuada para informáticos y matemáticos. El texto puede
reorganizarse y remezclarse. Es posible producir con él libros de texto
personalizados que tengan en cuenta los objetivos del curso y las preferencias
del docente. Está escrito en LaTeX.

Esta es la edición completa en español y cubre los 722 archivos de la fuente. Es
una edición independiente, asistida por IA y no oficial; no implica el respaldo
del Open Logic Project. Fuente exacta: commit
`9620cc73f9c8e0ad003c514a5d3748f29611c4c0`, árbol
`f67757bb9305b173634082ab4cefd5601a707a34`. Licencia: CC BY 4.0.
