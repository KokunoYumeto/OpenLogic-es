# The Open Logic Text — edición en español

Edición independiente y completa en español de *The Open Logic Text*, un manual
abierto de lógica formal y metalógica. Abarca lógica proposicional y de primer
orden, teoría de modelos, computabilidad, incompletitud, lógica modal, teoría de
conjuntos y teoría de la demostración.

Cubre los 722 archivos de la fuente congelada y conserva las fuentes TeX
editables, la notación matemática, los identificadores estructurales y las
referencias cruzadas. Fuente exacta: commit
`9620cc73f9c8e0ad003c514a5d3748f29611c4c0`, árbol
`f67757bb9305b173634082ab4cefd5601a707a34`. Es una edición asistida por IA y
no oficial; no implica el respaldo del Open Logic Project. Licencia: CC BY 4.0.
