## Qué cambia en 2026-08-19-r3

Esta versión sustituye únicamente el paquete de evidencia de la versión r2 para
eliminar rutas locales de la estación de trabajo. El texto traducido, la
cobertura, la composición de 160 × 230 mm y el diseño editorial se conservan.
Todos los artefactos públicos de r3 se sometieron a un control de privacidad
cerrado ante fallos, incluida la inspección de cada entrada de los ZIP.

El lector final tiene 1.160 páginas. SHA-256:
`05036FB18EAEBA1CBF59A3AED9A2123D6A662C89562C4B60D36E2369D9A14DDC`.

## Alcance y procedencia

La edición cubre los 722 archivos de la fuente congelada del Open Logic Project
en el commit `9620cc73f9c8e0ad003c514a5d3748f29611c4c0`, árbol
`f67757bb9305b173634082ab4cefd5601a707a34`.

Semánticamente es una traducción de esa fuente (DataCite: `IsTranslationOf`).
La API heredada de Zenodo no admite esa relación y la serializa mediante
`isVariantFormOf`; la procedencia exacta se declara además como
`isDerivedFrom`. Zenodo genera `IsVersionOf` desde el DOI de esta versión hacia
el DOI conceptual.

Esta edición no es una publicación oficial y no fue solicitada, revisada,
aprobada ni respaldada por The Open Logic Project. No se afirma revisión por
hablantes nativos ni validación comunitaria.
